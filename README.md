# darcula-zen
A modified Darcula theme with better colors and minimal eye strain.

## Installation
1. Download `darcula-zen-1.0.0.vsix`
2. Go to VS code extensions. In the top right corner, select the menu `...` icon and click `Install from VSIX...`
3. Select `darcula-zen-1.0.0.vsix` file
4. Go to VS code themes and apply it (VS code will ask this automatically upon installation anyway)

Thanks for the support! Enjoy your theme!
